## Design Context

### Users

JS and framework engineers evaluating `@watchstop/core` and a thin adapter. They open the docs site to see one live session, then read the spec and copy a binding.

### Brand Personality

Technical, sharp, slightly playful. The interface should feel like a workshop instrument, not a SaaS marketing page and not a personal art site.

### Aesthetic Direction

Terminal and chronograph craft. The live faces are the object. Chrome stays quiet. Keep Fumadocs light and dark. Do not restyle the whole docs theme. Do not borrow sm17p.me’s dark art-led atmosphere or Sentient / Pilcrow / Kola.

Anti-references: generic SaaS heroes, equal feature-card grids, purple/blue glow, nested cards, a fully centered stack with even padding everywhere.

### Design Principles

- Live faces are primary; copy and chrome are secondary.
- Tight groups, generous section breaks on a 4pt scale (4, 8, 12, 16, 24, 32, 48).
- Sibling spacing uses `gap`. No nested cards. No identical three-up card grid as the whole composition.
- Do not center every block. Brand can stay compact; gallery and copy left-align in one max-width column.
- One session stopwatch in the header, never overlapping GitHub or search.
